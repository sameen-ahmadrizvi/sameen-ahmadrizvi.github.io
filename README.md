# Dr Syed Sameen Ahmad Rizvi — Academic Website

A lightweight static academic website designed for free hosting on GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## Pages
- Home
- Journey So Far / Experience
- Publications
- Courses Taught
- Students Mentored
- Contact / Google Form embed

## Two items to replace before publishing
1. In `publications.html`, replace `REPLACE_WITH_GOOGLE_SCHOLAR_URL` with the exact Google Scholar profile URL.
2. In `contact.html`, replace the Google Form placeholder with the iframe code generated by Google Forms (`Send` → `<>` → Embed HTML).

## Optional personalisation
- Replace the initials avatar with a professional portrait.
- Add a downloadable CV PDF and a `CV` button on the home page.
- Add student names only where you are comfortable making them public.
- Add a custom domain later (for example, `sameenrizvi.in` or another domain you own).

## Publish on GitHub Pages
1. Create a GitHub repository named `YOUR_USERNAME.github.io` for a root personal site, or any repository name for a project site.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save. GitHub will publish the site.

## Publish on Cloudflare Pages
Connect the GitHub repository to Cloudflare Pages. This project has no build step; use the repository root as the output directory for direct static hosting.

## Publish on Netlify
Drag this entire folder into Netlify Drop, or connect the GitHub repository. No build command is required.

## Publish on Vercel
Import the GitHub repository as a new project. It is a static site and needs no framework-specific configuration.

## Local preview
Run from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
